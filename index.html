📖 Kullanım
1. Gerekli Dosyaları Ekleyin
<!-- Socket.IO -->
<script src="https://cdn.socket.io/4.7.4/socket.io.min.js"></script>

<!-- HaremAltin Plugin -->
<script src="haremAltin.min.js"></script>
2. HTML Element Oluşturun
<div id="haremAltin"></div>
3. Plugin'i Başlatın
<script>
HaremAltin.setConfigs({
    selector: '#haremAltin',
    tableClass: 'table table-striped',
    showChange: true,
    currencySymbol: '₺'
});

HaremAltin.connect();
</script>
⚙️ Konfigürasyon Seçenekleri
Parametre Varsayılan Açıklama
selector 'body' Tablonun render edileceği CSS selector
tableClass 'table table-striped' Tabloya uygulanacak CSS sınıfları
showHeader true Tablo başlığını göster/gizle
showChange true Değişim sütununu göster/gizle
currencySymbol '₺' Para birimi simgesi
onPriceUpdate null Fiyat güncellendiğinde çağrılacak callback
onConnect null Bağlantı kurulduğunda çağrılacak callback
onDisconnect null Bağlantı kesildiğinde çağrılacak callback
